CuePoint Privacy Policy

CuePoint does not send bookmark data off your device in local mode. There is no developer-operated sync server, advertising, or analytics in CuePoint.

Boundary Local mode (default) Cloud (BYOC) (optional)
Storage Stored only in your Firefox profile. Firefox profile + your own Firebase Realtime Database.
Transmission No bookmark data leaves your device. Only after you connect and grant Firefox permissions.
Developer access None — no developer-operated servers. None — synced directly to your own Firebase project.
01 On device

What CuePoint stores on this device

When you save a moment, CuePoint reads only the details of that specific YouTube watch page and stores the bookmark and any note you add in your Firefox profile. It does not record a history of videos you do not save.

Video & timestamp
The video ID, playback timestamp, and video title from the YouTube watch page.
Channel details
The available channel name and channel link shown on the watch page.
Your note
Any optional note you write when saving or editing the moment.

Exported JSON backups: An exported JSON file contains the bookmarks and notes in the active library; treat it as private if the contents are private.

02 Opt-in sync

What optional Firebase sync sends

Cloud sync is off by default. If you choose to connect and grant permission, Firebase sync uses the project you configure:

Google Firebase Authentication
Receives your Firebase sign-in email and password and issues session tokens. CuePoint stores the account configuration and tokens in your Firefox profile to keep sync working. It does not save your password in extension storage.
Your Firebase Realtime Database
Receives bookmarks in that cloud library: YouTube URLs, timestamps, titles, channel information, optional notes, and record identifiers and versions needed to sync changes.

Libraries are separate. Signing in does not copy existing local bookmarks to Firebase. The cloud library can receive them only if you explicitly copy or import them.

03 Your control

How to stop sync or remove data

Stopping sync

Pause sync
Switch to Local in the Cloud Sync panel.
Remove saved session
Log out in CuePoint to remove the saved session from this profile.
Revoke permissions
Revoke CuePoint’s optional permissions in Firefox’s Add-ons Manager.

These actions do not delete the data already in your Firebase project, nor do they clear cached bookmarks on the device.

Deleting stored data

Individual moments
Delete individual moments in the library they belong to.
All local data
To remove all local extension data from a profile, remove the extension from Firefox.
Cloud data & account
To remove your cloud data or authentication account, manage them separately in your Firebase project. Google handles data processed by Firebase under its Firebase privacy and security terms .
04 Support

Questions

Use the support contact on the CuePoint Firefox Add-ons listing.

Keep secrets private: Do not send passwords, tokens, or private notes with a support request.
