CuePoint Privacy Policy

CuePoint does not send bookmark data off your device in local mode. There is no developer-operated sync server, advertising, or analytics in CuePoint.

What CuePoint stores on this device

When you save a moment, CuePoint reads the video ID, playback timestamp, video title, and available channel name and link from the YouTube watch page. It stores that bookmark and any note you add in your Firefox profile. It does not record a history of videos you do not save. An exported JSON file contains the bookmarks and notes in the active library; treat it as private if the contents are private.

What optional Firebase sync sends

Cloud sync is off by default. If you choose to connect and grant permission, Firebase sync uses the project you configure:

  • Google Firebase Authentication receives your Firebase sign-in email and password and issues session tokens. CuePoint stores the account configuration and tokens in your Firefox profile to keep sync working. It does not save your password in extension storage.
  • Your Firebase Realtime Database receives bookmarks in that cloud library: YouTube URLs, timestamps, titles, channel information, optional notes, and record identifiers and versions needed to sync changes.

Libraries are separate. Signing in does not copy existing local bookmarks to Firebase. The cloud library can receive them only if you explicitly copy or import them.

How to stop sync or remove data

Switch to Local to pause sync, log out to remove the saved session from CuePoint, or revoke the optional permissions in Firefox’s Add-ons Manager. These actions do not delete the data already in your Firebase project, nor do they clear cached bookmarks on the device.

Delete individual moments in the library they belong to. To remove all local extension data from a profile, remove the extension from Firefox. To remove your cloud data or authentication account, manage them separately in your Firebase project. Google handles data processed by Firebase under its Firebase privacy and security terms.

Questions

Use the support contact on the CuePoint Firefox Add-ons listing. Do not send passwords, tokens, or private notes with a support request.
