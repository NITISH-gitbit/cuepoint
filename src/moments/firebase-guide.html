Firebase Cloud Sync Setup (BYOC)

Connect your own free Firebase Spark Plan project so your saved YouTube moments sync live across devices while staying 100% under your own Google account.

Step 1

Create a free Firebase project

Go to the Firebase Console, click Add project, name it (e.g., cuepoint), and stay on the free Spark plan ($0, no billing required).

Step 2

Enable Email/Password sign-in & add your user

Open Build → Authentication → Sign-in method, enable Email/Password, then go to the Users tab and click Add user to create the email and password you will use in the extension.

Step 3

Create a Realtime Database

Open Build → Realtime Database, click Create Database, choose your region, and start in Locked mode.
